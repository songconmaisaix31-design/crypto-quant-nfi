# Security

The project is not an automatic real-money trading system.

Current allowed activity:

- Dry-run.
- Shadow observation.
- Binance Spot Testnet practice.

Current forbidden activity:

- Mainnet Binance API keys.
- Real-money live trading.
- Futures, margin, leverage, or shorting.
- Withdrawal permission.
- Public FreqUI.
- API keys written to disk or git.
